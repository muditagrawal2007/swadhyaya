# Swadhyaya

Intuition-first Linear Algebra. Learn by playing, not by formula.

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000.

## Philosophy

No formula memorization. Every concept is taught as a 4-act experience:
1. **Puzzle** — a striking visual, no explanation
2. **Story** — plain English, no jargon
3. **Playground** — interactive widget where you DISCOVER the formula by playing
4. **Test** — 3-5 challenges that prove the intuition stuck
